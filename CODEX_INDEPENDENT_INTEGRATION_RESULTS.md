## Security, data integrity, and release blockers

1. **High — same-origin browser storage.** The current GitHub Pages routes for the original and 2.0 apps share `gcfd8hy5mb-ai.github.io`. Separate paths and service-worker scopes do not isolate localStorage. The 2.0 auth store keeps persistent bearer and refresh tokens for installed use. No exposure was demonstrated. Establish a dedicated origin or approve a reviewed alternative session architecture before using the paths as a security boundary.
2. **High — verify server-side grants and owner enforcement.** The transport and recovery code validate owner and revision information and the mocked account tests passed. The candidate has no deployed Supabase RPC definitions or grant inventory to audit. Review the actual `mlc2_v1_*` functions and their table and execution permissions, then verify signed-in backup and fill-only recovery with an authorized test account. Client-side checks are insufficient to prove server-side isolation.
3. **High — complete same-iPhone acceptance of the review build.** Existing user acceptance for saved weekly programs and Home Next Session remains valid for the previously tested build. This review did not directly test physical iPhone Home Screen status-bar rendering, suspend/resume update, keyboard/focus, workout recovery, or a live account recovery on the new branch. Deployment and physical verification require an authorized isolated 2.0 build. A second device is not required.
4. **Medium — cross-context and crash consistency.** Weekly routine, schedule, and manual-selection data still span multiple localStorage keys. Quota/injected write failures are covered by rollback. Process termination during writes and independent contexts without compatible locking are outside those guarantees. The prior Web Locks fallback caveat remains. Draft safety fixes cover the tested route and do not amount to a durable multi-writer transaction.
5. **Conditional — content and entitlements.** Free/Pro remains a preview preference, with `paidSubscription:false`; there is no paid billing entitlement. The 81 withheld demonstrations remain a content gap if replacement requires a finished 344-image library.
6. **Release packaging.** Draft PR #9 compares the right predecessor and remains draft. Latest fetched `main` is 62 commits ahead of the common base and the incoming review candidate is 871 ahead on its side. The GitHub Pages workflow packages a pinned candidate and currently names the incoming `31d1a8d` source. A blind merge into `main` would bypass the reviewed packaging route. Use a tested pin and a recoverable release package only after acceptance and explicit cutover approval.

No production refs, Pages deployments, original repository files, or workout data were changed in this review.
